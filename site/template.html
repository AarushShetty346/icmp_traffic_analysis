Detecting ICMP covert timing channels from inter-packet delays

A sender can hide bits in the gaps between ping packets: a short gap for 0, a long gap for 1. This bench simulates normal and timing-encoded ICMP Echo Requests as the receiver sees them, computes Δtᵢ = tᵢ − tᵢ₋₁, and runs the project's two detectors on fixed windows. Change the network conditions and watch where each detector holds up or starts raising false alarms.

What the numbers say

The planned 0.75 / 1.25 s channel is easy to catch: its gaps spread about 0.25 s around the mean, while ordinary ping spreads a few milliseconds. Both detectors find every channel window.

The trouble is false alarms. A baseline measured on a clean LAN flags all normal traffic once 20 ms of jitter appears. A baseline measured under the same conditions fixes that. The fixed 0.1 s rule stays quiet until jitter reaches about 100 ms and then fails.

The subtle 0.95 / 1.05 s channel slips under the fixed rule completely and hides inside 100 ms of jitter even for the matched baseline. Network noise and the channel's own spread overlap.

Limits of these numbers

They come from the simulator, not the lab testbed, so they show how the pipeline behaves and which effects to look for. Real captures replace them for Review 2 and 3.

Loss is handled with ICMP sequence numbers: a gap across a missing request is skipped, so one lost packet does not look like a deliberate 2 s gap.

Pipeline

  1. CaptureReceiver-side tshark capture of Echo Requests
  2. Filter flowSource, destination and ICMP identifier
  3. Inter-packet delayΔtᵢ = tᵢ − tᵢ₋₁, skipping gaps across lost requests
  4. WindowsFixed windows of 8, 16 or 32 requests
  5. FeaturesMean, variance, std, CV, IQR, entropy, off-nominal share
  6. DecideFixed rule vs p95 of the normal baseline
  7. ScoreDetection rate, false-positive rate, decoding accuracy

Run on lab captures

tshark -r normal1.pcap -Y "icmp.type == 8" -T fields \
  -e frame.time_epoch -e ip.src -e ip.dst \
  -e icmp.ident -e icmp.seq -E header=y -E separator=, \
  > normal1.csv

python -m icmp_detector baseline normal*.csv --window 32 --out baseline.json
python -m icmp_detector detect test.csv --baseline baseline.json
python -m icmp_detector evaluate --baseline baseline.json \
  --normal test_normal*.csv --channel test_channel*.csv --bits 010101...

python -m icmp_detector study --out results
